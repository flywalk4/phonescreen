# PhoneScreen

iPhone как пристыкованный вспомогательный экран Mac: страницы-виджеты (музыка, мониторинг, …), переключение хоткеями, свайпом, а позже — уводом курсора Mac на экран телефона.

Виджеты рисуются нативно на iPhone; Mac-агент (menu bar) шлёт только данные. Связь поднимается сразу по всем доступным каналам, трафик идёт по лучшему:

| Приоритет | Канал | Нужно |
| --- | --- | --- |
| 1 | USB (через системный `usbmuxd`) | кабель, iPhone доверяет Mac |
| 2 | Wi-Fi LAN (Bonjour `_phonescreen._tcp`) | общая сеть |
| 3 | Wi-Fi P2P (AWDL) | ничего — Wi-Fi включён, устройства рядом |
| 4 | Bluetooth LE (L2CAP) | Bluetooth включён; без обложек и иконок — канал узкий |

Пропал канал — сессия продолжает жить на следующем, состояние переотправляется.

## Страницы

| Страница | Откуда данные |
| --- | --- |
| Музыка | Музыка / Spotify на Mac (AppleScript) |
| Календарь | Календарь iCloud прямо на iPhone (EventKit) |
| Напоминания | Напоминания iCloud прямо на iPhone (EventKit): отметить, добавить |
| Заметки | Apple Notes через Mac (у iOS нет API): список, текст, новая заметка, «Открыть на Mac» |
| Команды | Dock-приложения, «Команды» (Shortcuts) и системные действия Mac |
| Мониторинг | CPU/GPU/RAM/сеть Mac, графики за минуту |
| Погода | Геопозиция iPhone + Open-Meteo |

При первом открытии страниц iOS/macOS спросят доступ (календарь, напоминания, геопозиция, управление «Заметками»).

## Свои виджеты (JavaScript)

Логика виджета выполняется на Mac в песочнице JavaScriptCore (сеть — только на объявленные HTTPS-хосты, секреты — из Связки ключей), интерфейс — декларативный `view.json`, который телефон рисует нативно. Установка: Mac → «Виджеты…» (каталог с GitHub, из папки, папка разработки с автоперезагрузкой). Документация для авторов — [`catalog/README.md`](catalog/README.md), скилл для ИИ-агентов — [`skills/phonescreen-widget`](skills/phonescreen-widget/SKILL.md).

```bash
python3 scripts/validate-widget.py catalog/widgets/<id>   # статическая проверка
PhoneScreen --widget-test catalog/widgets/<id>            # запуск в настоящей песочнице
python3 scripts/build-catalog.py                          # пересобрать catalog/index.json
python3 scripts/claude-code-bridge.py install             # необязательный мост для «Claude Code»: точные % лимитов
```

## Структура

- `Packages/PhoneScreenKit` — общий код: протокол (`Message`, кадры `[UInt32 BE длина][JSON]`), `ByteChannel`, `ChannelPool`.
- `Mac/` — menu bar агент: `USBMuxClient`, `BonjourBrowser`, провайдеры данных, хоткеи.
- `iOS/` — клиент: `Listener` (TCP :47800 + Bonjour), страницы.

## Сборка

```bash
brew install xcodegen
xcodegen generate
open PhoneScreen.xcodeproj
```

- **Mac**: схема `PhoneScreenMac`, подписывается локально («Sign to Run Locally»). Иконка появится в строке меню. При первом запросе трека macOS спросит разрешение на управление Музыкой/Spotify.
- **iPhone**: схема `PhoneScreeniOS`. Для реального устройства укажите команду: `DEVELOPMENT_TEAM=XXXXXXXXXX xcodegen generate` (или в Xcode → Signing). С бесплатным Apple ID сборка живёт 7 дней, потом просто пересобрать.
- При первом запуске iOS спросит доступ к локальной сети — нужно разрешить, иначе Wi-Fi/P2P не заработают (USB работает и без этого).

## Расположение iPhone

Меню агента → «Расположение iPhone…» (при первом запуске окно открывается само). Как в «Мониторах»: все экраны Mac и телефон в реальных пропорциях.

- перетащите телефон к любому свободному краю любого экрана — он прилипнет;
- `R` / `⇧R` или кнопки — поворот на 90° (вертикально, горизонтально, вверх ногами);
- зелёная линия — участок края, через который курсор будет переходить на телефон.

Телефон берёт ориентацию из этой настройки, а не из акселерометра, поэтому работает и лёжа на столе.

## Хоткеи на Mac

- `⌃⌥←` / `⌃⌥→` — предыдущая/следующая страница
- `⌃⌥1…9` — конкретная страница
