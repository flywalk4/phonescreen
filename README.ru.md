# PhoneScreen

**iPhone как второй экран для Mac.**

Живые виджеты: музыка, нагрузка системы, календарь, погода, крипта, лимиты Claude Code, фоторамка и мини-игры.<br>
Уведите курсор Mac за край дисплея — и он окажется на телефоне.

### Страницы

У каждого виджета три раскладки: `full` (вся страница), `medium` (половина) и `small` (плитка), так что их можно сочетать. На странице — один виджет, два, «один большой + два маленьких», сетка 2×2, три в столбик или сетка 2×3 из шести плиток.

## 🎨 Темы

<p align="center"><img src="docs/images/themes.png" alt="Темы из каталога" width="100%"></p>

Тема — один `theme.json`: цвета, шрифт, скругление, вид карточек (`flat`, `glass` или `ascii`) и живой фон по желанию. Её подхватывают и встроенные виджеты, и виджеты из каталога. В ASCII-теме полосы становятся `[####....]`, кольца — процентами, иконки — символами, а обложки альбомов — ASCII-артом.

**В каталоге:** Catppuccin · Dracula · Gruvbox · Nord · Tokyo Night · Solarized · Synthwave · «Графит» · «Пастель» с бенто-карточками · янтарный и e-ink терминалы · «Зима» со снегом и «Дождливый вечер».

<details>
<summary><b>🎛️ Тонкая настройка: любая тема под себя</b></summary>
<br>

Mac → **Темы…**, под списком тем — **Тонкая настройка**. Она меняет выбранную тему:

- акцентный цвет, вид карточек (заливка, стекло, ASCII), шрифт и скругление
- живой фон и его скорость — или размытое фото из «Избранного» iPhone
- промежутки между карточками, поля экрана, отступы внутри карточек
- прозрачность карточек (чтобы просвечивал фон) и мягкая тень
- размер текста, автолистание страниц, лёгкая вибрация при нажатии
- время и дата у Dynamic Island и точки страниц

Любую страницу можно сделать «без карточек» — виджеты прямо на фоне. То же тема может задать блоком `layout` в `theme.json`.

</details>

## 🖥️ Второй экран

Не трансляция и не виджет: у macOS появляется **настоящий дополнительный дисплей** ровно там, где телефон стоит в «Расположении». Перетащите любое окно за край — и оно окажется на телефоне: Safari, Xcode, видео, Telegram. Это обычное окно Mac, так что клавиатура, Mission Control и полноэкранные приложения работают как всегда.

**Как включить:** добавьте виджет **«Второй экран»** на страницу с раскладкой **«Один»** и перелистните на неё на телефоне. Дисплей существует, пока страница открыта; уйдёте с неё — через 5 секунд он исчезнет, окна переедут на основной экран и вернутся в следующий раз. В первый раз macOS попросит **Запись экрана** (чтобы транслировать картинку) и **Универсальный доступ** (чтобы касания стали кликами).

| На телефоне | На Mac |
| --- | --- |
| Тап | Клик |
| Ведёте одним пальцем | Перетаскивание, в том числе окон |
| Долгое нажатие (½ с) | Правый клик |
| Два пальца | Прокрутка |
| Печатаете на клавиатуре Mac | В активное окно, как на любом мониторе |

- **Чётко:** режим HiDPI (2 пикселя на точку), как на Retina, аппаратное кодирование H.264 до 60 кадров в секунду.
- **Нужен USB или Wi-Fi:** по Bluetooth видео не пролезет, поэтому без кабеля и Wi-Fi страница так и скажет и подождёт.
- **Поверните телефон** — дисплей повернётся вместе с ним: широкий рабочий стол боком, высокий — вертикально.
- **Отключили его в «Системные настройки → Мониторы»?** Телефон предложит включить снова, а не включит сам за вашей спиной.

<details>
<summary><b>Как это устроено</b></summary>
<br>

Mac создаёт дисплей приватным API `CGVirtualDisplay` в форме телефона (не меньше 640 точек по короткой стороне — меньше macOS не даёт режим HiDPI), снимает его через ScreenCaptureKit, кодирует кадры VideoToolbox и шлёт их по тому же каналу USB / Wi-Fi, что и виджеты. Телефон декодирует их в `AVSampleBufferDisplayLayer` и отправляет обратно касания, а Mac превращает их в события мыши на этом дисплее. Из-за приватного API PhoneScreen и не может попасть в Mac App Store.

</details>

## 📦 Установка

Готовые сборки лежат на странице [**Releases**](https://github.com/flywalk4/phonescreen/releases/latest). Они не подписаны Apple (для этого нужен платный аккаунт разработчика), поэтому на каждой платформе есть один лишний шаг. Собрать самому — см. [Быстрый старт](#-быстрый-старт).

<details open>
<summary><b>💻 Mac</b> — <code>PhoneScreen-x.y.z.dmg</code>, macOS 14+, Apple silicon и Intel</summary>
<br>

1. Откройте `.dmg` и перетащите **PhoneScreen** в **Программы**.
2. Откройте PhoneScreen. macOS скажет, что не может проверить программу на вредоносное ПО, — нажмите **Готово**.
3. Откройте **Системные настройки → Конфиденциальность и безопасность**, пролистайте вниз и нажмите **Всё равно открыть** напротив PhoneScreen, подтвердите. Дальше программа открывается как обычно.

Или в Терминале, до первого запуска:

```bash
xattr -dr com.apple.quarantine /Applications/PhoneScreen.app
```

После обновления macOS может снова попросить **Универсальный доступ** и **Запись экрана** — выключите и включите PhoneScreen в этом списке.

</details>

<details open>
<summary><b>📱 iPhone</b> — <code>PhoneScreen-x.y.z.ipa</code>, iOS 18+</summary>
<br>

Установите со своим Apple ID через [Sideloadly](https://sideloadly.io) или [AltStore](https://altstore.io):

1. Подключите iPhone к Mac кабелем, откройте Sideloadly, перетащите в него `.ipa`, введите Apple ID и нажмите **Start**.
2. На iPhone: **Настройки → Конфиденциальность и безопасность → Режим разработчика** → включить (телефон перезагрузится), затем **Настройки → Основные → VPN и управление устройством** → доверять своему Apple ID.
3. С бесплатным Apple ID подпись живёт 7 дней: переустановите тот же `.ipa` через Sideloadly или пусть AltStore обновляет её сам по Wi-Fi.

</details>

Дальше поставьте телефон и добавьте виджеты — шаги 3–5 из [Быстрого старта](#-быстрый-старт).

## 🚀 Быстрый старт

> **Нужно:** macOS 14+, iOS 18+, Xcode 16+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen).

```bash
brew install xcodegen
git clone https://github.com/flywalk4/phonescreen.git && cd phonescreen
xcodegen generate
open PhoneScreen.xcodeproj
```

1. **Mac:** схема `PhoneScreenMac`. В строке меню появится иконка. При первом запросе трека macOS спросит разрешение на управление Музыкой или Spotify.
2. **iPhone:** схема `PhoneScreeniOS` на телефоне. Команду укажите в Xcode → Signing или так: `DEVELOPMENT_TEAM=XXXXXXXXXX xcodegen generate`. Разрешите доступ к **локальной сети**, когда iOS спросит (USB работает и без этого).
3. **Расположение:** меню → **Расположение iPhone…**. Перетащите телефон к любому краю любого экрана — курсор будет переходить через зелёный участок. `R` / `⇧R` — поворот.
4. **Виджеты и темы:** меню → **Виджеты…** / **Темы…**.
5. **Второй экран (по желанию):** поставьте виджет **«Второй экран»** на страницу с раскладкой «Один». В первый раз macOS попросит **Запись экрана** (для трансляции) и **Универсальный доступ** (чтобы касания стали кликами). Дисплей появляется, пока эта страница открыта на телефоне, и исчезает через 5 секунд после ухода с неё; окна с него переезжают на основной экран и возвращаются в следующий раз.

> [!NOTE]
> Приложения и виджеты каталога говорят по-английски (по умолчанию) и по-русски: язык выбирается внизу боковой панели настроек, телефон переключается вместе с Mac. С бесплатным Apple ID сборка на iPhone живёт 7 дней — потом просто пересоберите. Ориентацию телефон берёт из настройки расположения, а не из акселерометра, так что работает и лёжа на столе.

| Хоткей | Действие |
| --- | --- |
| <kbd>⌃</kbd><kbd>⌥</kbd><kbd>←</kbd> / <kbd>⌃</kbd><kbd>⌥</kbd><kbd>→</kbd> | Предыдущая / следующая страница |
| <kbd>⌃</kbd><kbd>⌥</kbd><kbd>1</kbd>…<kbd>9</kbd> | Перейти к странице |

<details>
<summary><b>Что есть у автора виджета</b></summary>
<br>

- **16 типов узлов:** стеки, сетки, списки, блоки, текст, SF Symbols, шкалы, прогресс-бары, линейные, площадные и столбчатые графики, кнопки, пиксельные спрайты, слои и анимированные сцены. Каждый узел следует теме.
- **Типизированные настройки:** `text`, `choice` (выпадающий список с `options`), `toggle` (переключатель) или `number` (ползунок или поле со стрелками с `min`/`max`/`step`/`unit`). Mac рисует их сам, изменения сразу доходят до телефона.
- **Песочница:** `fetch` (только объявленные хосты), секреты из Связки ключей, настройки, 64 КБ хранилища, чтение объявленных файлов и помощники для чисел и дат в `format`.
- **Автодополнение:** JSON Schema в [`schemas/`](schemas) для `view.json`, `manifest.json` и `theme.json` в VS Code.
- **Любой язык:** тексты — в `strings.json` (`t("key")` в коде, `{{t.key}}` в вёрстке), с формами множественного числа; числа и даты из `format` — на языке пользователя.
- **Автоперезагрузка:** Mac → **Виджеты → Папка разработки…** — виджет обновляется на телефоне при каждом сохранении.
- **CI:** проверяет каждый виджет и тему каталога, прогоняет фикстуры, собирает оба приложения и снимает настоящие скриншоты в Simulator.

```bash
python3 scripts/validate-widget.py catalog/widgets/<id>   # статическая проверка
PhoneScreen --widget-test catalog/widgets/<id>            # запуск в настоящей песочнице
python3 scripts/build-catalog.py                          # пересобрать catalog/index.json
python3 scripts/claude-code-bridge.py install             # необязательный мост для «Claude Code»: точные % лимитов
```

## 🔍 Как это устроено

```
Mac (агент в строке меню)                              iPhone
┌──────────────────────────────┐   USB · Wi-Fi ·    ┌──────────────────────────┐
│ провайдеры: музыка, система… │   AWDL · BLE       │ страницы виджетов        │
│ JS-виджеты в JavaScriptCore  │ ─────────────────▶ │ SwiftUI, темы            │
│   provider.js → данные       │   JSON-кадры       │ view.json + данные → UI  │
│ захват курсора у края        │ ◀───────────────── │ нажатия, действия, курсор│
└──────────────────────────────┘                    └──────────────────────────┘
```

<details>
<summary><b>Каналы связи</b></summary>
<br>

| Приоритет | Канал | Нужно |
| :-: | --- | --- |
| 1 | USB (через системный `usbmuxd`) | кабель, iPhone доверяет Mac |
| 2 | Wi-Fi LAN (Bonjour `_phonescreen._tcp`) | общая сеть |
| 3 | Wi-Fi P2P (AWDL) | ничего — Wi-Fi включён, устройства рядом |
| 4 | Bluetooth LE (L2CAP) | Bluetooth включён; без обложек и иконок — канал узкий |
